# 法意瑞 12 日慢享全景 · 2027

🇮🇹 🇨🇭 🇫🇷 · 2027.5.12 – 5.23

**上线地址**：https://ruiqilyu.github.io/euro-2027/

一个单文件 HTML 的交互式旅行手册，零外部依赖，手机能开、离线能看、同行人分享即用。

## 特性

- ⏱️ 顶部大号倒计时（每秒跳，支持北京/欧洲时区切换）
- 🗺️ 手绘风格 SVG 总览地图，按国分色
- 📅 逐日行程 Tab，每个地点点击直达 Google 地图，每天顶部一键"全天多点导航"
- 🎫 场馆 & 交通订票入口（含建议下单时机）
- 📝 待办清单（纯列表，避免多人勾选状态混乱）
- 🎒 行李打包清单（65 项官方基础清单 + 手机随时添加）
- 🌗 深色模式跟系统自动切换
- ⚠️ 已核对闭馆日、时间冲突、天气备用日

## 开发

单文件 `index.html`，无需构建，直接编辑推送即可。
